yang dipakai adalah fallback native:

```text
start_synapse
  -> set_run_id
  -> wait_for_synapse (Until + get status)
  -> fail_if_not_success
```

Activity types: `WebActivity`, `SetVariable`, `Until`, `IfCondition`, `Fail`.
Tidak ada Wait 10 menit buta. ADF memeriksa status Synapse setiap 60 detik.

Trigger `tr_daily_0600_wib` ada, 23:00 UTC atau 06:00 WIB, status **Stopped**.
